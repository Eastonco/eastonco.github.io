# Finally finished

After YEARS of procrastination, I finally got around to building out this site. 


## Site History

It's been a long time coming. Originally, the site was a basic static site hosted on GH Pages. However, there were many short comings where I wanted to do other side projects that the site couldn't scale to due to it's static nature.

From there, I had an AWS kick and decided it'd be a gReAt idea to host on AWS. (Spoiler: this was a terrible idea). AWS is great, don't get me wrong. We use it all the time at my current company Expedia Group. However for simple use cases, the amount of overhead between setting up S3, subnets, domain rounting, and everything else SUCKS.

Origianlly, AWS was hosting all my domains - eastonco.net, connoreaston.com, and more recently, eastonco.dev (Collecting these suckers like infinity stones...). Unfortuneatly, there's no easy way to setup URL redirection without all this extra complexity forwarding to S3 and subnets and other enterprise problems.

Decided to switch to cloudflare and I couldn't be happier. First of all: Free!!! AWS was costing me ~$5/month, which, not a lot, but still not free. For personal projects, I've loved using cloudflare and they have a ton of built in features like analytics, DDoS productions, and other goodies.

Now, you're probably dying to know what this built with. Well here ya go

* Next.js hosted via Vercel
* React
* Motion.dev for UI aniamtions
* Supabase backend
* PostHog for analytics (love them)
* MDX for the blog you're reading
* Tailwind CSS


# Vibe Coding?

Now historically speaking, I'd consider myself more of a realist when it comes to using AI. It's an advanced auto complete at best. However it does have some huge benefits for summarizing and research.

Reguardless, I wanted to put it through it's paces and see how good the current "Vibe Coding" enviornment is.

I'm mildly impressed but it's far from perfect. Mostly built with Claude Sonnet 4, the AI really strggles keeping attention to detail when prompting on larger projects. A lot of the visual elements had to be rewriteen multiple times as it couldn't one shot a project very often.

Furthermore, despite prompting for components to be easy to maintian and reuse, most of the code is straight 🗑️. It's sloppy, hard to read, and there's no consistent global style or components. Which, if you're coding professionially, should be a huge priority. 

So while the site may look nice from the outside, I'll have to manually refactor a lot of this if I want to maintian it long term. But that's the beauty of AI right? You're able to generate tons of code in such a short amount of time that the opporunity cost is near 0.
